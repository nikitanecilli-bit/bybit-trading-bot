## 2. Предварительно подтверждённые факты
- README описывает `Bybit_Trading_Engine_v14_research.py` как research/backtest simulator, не подключённый к размещению ордеров Bybit.
- Данные, использованные в ряде исследований, — Binance OHLCV proxy; попытка свежей валидации Bybit ранее получила HTTP 403. Это ограничивает переносимость выводов на реальное исполнение Bybit.
- Репозиторий содержит несколько исторических workflow и экспериментальных скриптов; перемещение файлов до проверки путей может сломать воспроизводимость.
- В корне уже находятся README, рабочие правила и журнал экспериментов; добавлена единая навигация и инструкция агенту без перемещения legacy-файлов.
- E09 — факторный эксперимент execution × body gate × next-open gap gate; его корректность требует сверки run SHA, workflow SHA, логов и артефактов. Результаты из журнала пока считать предварительными до этой сверки.

## 3. Критические направления аудита (не закрыты)
- Временная модель: timestamp semantics, закрытые/незакрытые свечи, синхронизация символов, warm-up, границы fold.
- Отсутствие look-ahead в сигналах, контексте, stop/TP и статистике.
- Порядок событий внутри свечи, stop/target collision, гэпы через стопы и лимиты.
- Market/limit fills: spread, queue position, partial fills, latency, cancel/replace, adverse selection.
- Комиссии maker/taker, slippage, funding и корректность их применения при входе/выходе.
- Position sizing, leverage, margin, общий капитал, портфельный риск, concurrency, дневные лимиты.
- Реальная согласованность research engine с live-кодом (если он существует в других ветках/файлах).
- Метрики: PF, expectancy, drawdown, R multiple, MAE/MFE и агрегирование по сделкам/портфелю.
- Дублирование экспериментов, multiple testing, выбор инструментов/периодов, holdout leakage.
- Проверка датасетов: источник, диапазоны, пропуски, дубли, timezone, survivorship universe.

## 4. Уже известные методологические риски
- Лимитное исполнение по касанию OHLC — оптимистичное приближение, не моделирует очередь, спред, частичные исполнения и adverse selection.
- Binance OHLCV не является Bybit execution data.
- Funding в ряде прошлых исследований не моделировался.
- Многофакторные сетки и отбор лучших символов/параметров создают multiple-testing и selection bias.
- Положительный итог может быть сконцентрирован в одном fold; нужно показывать каждый период.
- Исторические результаты разных экспериментов нельзя сравнивать напрямую без проверки совпадения universe, folds, config, costs и движка.
