# Quant Analytics dashboard prototypes

Все файлы в этой папке — standalone HTML/JS аналитические прототипы. Они не являются торговым движком и не участвуют в формировании ордеров.

## Версии и рекомендуемое использование

| Файл | Статус | Примечание |
|---|---|---|
| `Quant Analytics Dashboard v2.3.html` | Основной standalone UI-прототип для просмотра | Самая полная версия в этой подборке; поддерживает импорт JSON/CSV и имеет seeded demo. Перед использованием реального журнала сверять все поля/метрики с текущим `TradeRecord`. |
| `Quant Analytics Dashboard v2.2 + AI Lab (Full Single-File).html` | Архивная standalone версия | Сохранена для сравнения; не развивать параллельно v2.3 без отдельного решения. |
| `Quant Analytics Dashboard v2.2 + AI Lab (Part 1 of 3).html` / `Part 2 of 3.html` | Исходные фрагменты | Не самостоятельный полный релиз. |
| `duplicates/` | Точные копии multipart-фрагментов | Git blob SHA совпадают с соответствующими файлами в родительской папке; хранить только для provenance. |
| `Quant AI Lab Plugin ... (Complete).js` | Отдельный plugin prototype | Содержит renderer и расчётные функции; не подключён к текущему дашборду/CI. |
| `Quant AI Lab Plugin ... (Part 3.1).js` | Частичный фрагмент | Не полный релиз и не заменяет Complete. Не подключать одновременно. |

## Важные ограничения

1. v2.3 содержит `genDemo(seed, N=180)` с намеренно встроенными различиями по сессиям/токенам. Seeded demo предназначена для проверки интерфейса и аналитических функций, а не для доказательства торгового edge.
2. Demo PnL нельзя цитировать как результат бэктеста. При импорте реальных данных нужно убедиться, что источник переключён с demo на импортированный журнал.
3. Текущий engine `TradeRecord` использует `r_multiple` как NET R и хранит фактический `risk_usdt`. Старые dashboard fallbacks, восстанавливающие риск из `gross_pnl / r_multiple`, не эквивалентны фактическому risk denominator и могут исказить R.
4. Канонические gross/net, fees, slippage, funding, equity и drawdown должны приходить из engine run artifact, а не пересчитываться UI по альтернативным формулам.
5. AI plugin не считается безопасным, пока его расчёты не покрыты tests на нулевых значениях, знаках комиссий/rebates, отсутствующих полях, дубликатах, неизвестной стороне, времени и согласованности бухгалтерии.

## Решение

Сохранить все исторические версии. Для визуального просмотра начинать с v2.3, но не использовать её выводы для изменения стратегии. Для количественных экспериментов первичен Python engine + versioned run artifact + experiment registry.
