## Правила чтения результатов

- Успешный CI подтверждает только выполнение перечисленных технических проверок.
- Рыночные backtest/walk-forward не запускаются при push или pull request; для них создан отдельный workflow с ручным запуском.
- Binance OHLCV — proxy для Bybit, не доказательство реального исполнения на Bybit.
- PnL независимых single-symbol прогонов нельзя складывать и трактовать как shared-capital portfolio result.
- Любой результат должен сопровождаться данными, параметрами, версиями кода, costs и ограничениями модели исполнения.
