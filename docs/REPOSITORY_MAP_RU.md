# Карта репозитория

| Путь | Назначение |
|---|---|
| `.github/workflows/` | Технический CI и отдельные вручную запускаемые исследовательские workflow |
| `data/archives/cryptofetch/` | Неизменяемые исходные ZIP-архивы CryptoFetch |
| `dashboards/v15/` | Экспорт HTML/PDF дашборда v15 и инструкция |
| `dashboards/quant_analytics/` | Legacy HTML/JS-части Quant Analytics |
| `docs/audits/` | Аудиты кода и исследовательских ограничений |
| `docs/reports/` | Исторические backtest и диагностические отчёты |
| `docs/operations/` | Инструкции и вспомогательные материалы |
| `research/legacy_tools/` | Изолированные standalone-прототипы |
| `scripts/` | Сбор данных, запуск анализа и технические утилиты |
| `tests/` | Регрессионные тесты |
| корень | README, пример env, исследовательский движок и downloader |

Движок и downloader оставлены в корне, поскольку исследовательские скрипты импортируют их напрямую. Не перемещайте их без отдельной проверки импортов и воспроизводимости.
