# Диагностика пробойной стратегии по рыночным режимам

## Методика

- Источник: `/mnt/data/v14_breakout_thresholds/trade_journal.csv`, только вариант BASE; 3241 сделок до merge.
- Режим на входе определён по последнему полностью закрытому часовому бару (без использования будущего часа).
- ADX(14) на часовых свечах: <18 — боковой/слабонаправленный; 18–25 — переходный; ≥25 — выраженный тренд. Это диагностические пороги, не оптимизированные.
- ATR(14)/close — относительная волатильность; низкая/высокая определены относительно 30-дневных rolling 30-го/70-го процентилей, рассчитанных только по прошлым значениям.
- PnL/R взяты из журнала существующего бэктеста; это не новый независимый backtest и не доказательство причинности.
- Макс. просадка в таблицах — просадка последовательности сделок в USDT, не портфельная equity curve с реальными временными пересечениями и капиталом.

## Ограничения и интерпретация

- Если одна категория содержит мало сделок, её результат нельзя считать надёжным.
- ADX и ATR измеряют разные вещи: направленность и масштаб колебаний.
- Сравнение по режимам может иметь selection bias: режимы не рандомизированы, а результат зависит от символа, времени и частоты сделок.
- Следующий шаг после диагностики — зафиксировать правило фильтра и оценить его на последовательном walk-forward/OOS, сравнивая с BASE на тех же датах, с учётом пропущенных сделок, комиссий и проскальзывания.
- Не запускать на реальном счёте на основании этого анализа одного.
