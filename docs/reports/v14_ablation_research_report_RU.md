# Исследовательский бэктест Bybit Trading Engine v14 — A–F

**Статус:** исследовательский прогон; не готовый сигнал для реальной торговли.

## Данные
- Источник: локальные исторические CSV из набора, уже доступного в проекте; повторное обращение к Bybit не выполнялось.
- Инструменты: BNBUSDT, BTCUSDT, DOGEUSDT, ETHUSDT, PEPEUSDT, SOLUSDT, SUIUSDT, XRPUSDT.
- Таймфрейм: 15 минут.
- Период открытия свечей: 2026-04-29 00:00 UTC — 2026-10-26 00:00 UTC.
- По 17 281 свечей на инструмент; у всех восьми одинаковая временная сетка. Проверка: 0 дубликатов, 0 пропусков/неравномерных 15m интервалов, 0 некорректных OHLC-свечей.
- Данные содержат Trade OHLCV. В них нет native Mark Price и точной истории funding. Поэтому этот прогон оценивает сигналы и приблизительные торговые издержки, но не воспроизводит полностью реальное исполнение и funding.

## Как считали
- Использован движок `Bybit_Trading_Engine_v14_Audit_Fixed_v4_download.py` с его штатной логикой входов, выходов, комиссий и проскальзывания.
- В каждой комбинации инструмент тестировался отдельно со стартовым капиталом 10 000 USDT, риском 1% на сделку, одной одновременно открытой позицией.
- Kill-switch и дневной стоп были ослаблены до 999% **только для диагностического полного периода**, чтобы остановка по просадке не обрезала оставшуюся историю. Это не тест нормального риск-режима.
- Суммарные PnL по вариантам — сумма восьми независимых прогонов с суммарным начальным капиталом 80 000 USDT; это не единая синхронная портфельная кривая. Max DD в таблице по каждому активу, не pooled.
- EMA50 1h рассчитывается по закрытиям завершённых часовых свечей, восстановленным из 15m свечей с отметкой открытия :45; для каждого сигнала использована только доступная к тому моменту EMA.
- Вариант E: EMA-фильтр, H1-long-only, `stop_atr_mult=2.2`, минимум `stop_dist / entry_price >= 0.85%`.

## Варианты
- A — базовая стратегия.
- B — H2 отключена.
- C — только H1 Long.
- D — H1 Long + фильтр EMA50 на 1h.
- E — D + ATR stop multiplier 2.2 + минимум ширины стопа 0.85%.
- F — только H2 Short.

## Интерпретация
1. Ни один из шести вариантов не оказался прибыльным после заложенных комиссий и проскальзывания ни на одном из восьми активов.
2. Базовый вариант создаёт слишком большой оборот: 8 302 сделки, приблизительно 74.3k USDT издержек против лишь 2.2k валовой прибыли.
3. H2 Short имеет лучший валовой PF из вариантов (1.08), но его валовая прибыль +7.4k не покрывает около 59.1k издержек. Это не подтверждённое торговое преимущество в текущей модели.
4. E — наименее убыточный по сумме вариант за счёт резкого сокращения сделок (659 вместо 8 302), но он имеет отрицательный gross PnL (-2.58k) и gross PF 0.898. Следовательно, улучшение относительно baseline не означает появления edge.
5. Отключение H2 само по себе не исправляет систему: B остаётся отрицательным до издержек.
6. Результаты указывают на необходимость переработки сигналов/выходов, а не просто добавления фильтров. Нельзя объявлять ни один вариант готовым к реальной торговле.

## Ограничения и следующий этап
- Нет native Mark Price, funding settlements, стакана, очереди maker-исполнения и реальных частичных исполнений.
- Не проводился полноценный независимый walk-forward / untouched out-of-sample тест. A–F — скрининг гипотез на одном историческом окне.
- Риск-механизмы были ослаблены для полной атрибуции; реальные запуски с kill-switch могут остановиться раньше.
- Следующий рациональный этап: проверить логику входа/выхода и структуру затрат; затем зафиксировать параметры и провести отдельный хронологический holdout-тест, не используя его для подбора.
