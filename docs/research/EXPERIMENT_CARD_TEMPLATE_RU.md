## Контроль целостности

- [ ] Baseline не перезаписан.
- [ ] Гипотеза и критерии были зафиксированы до запуска.
- [ ] Нет look-ahead.
- [ ] Сохранены все результаты, включая отрицательные.
- [ ] Universe не выбран по результату того же тестового периода.
- [ ] Затраты и sizing одинаковы в baseline и candidate.
- [ ] Per-symbol результаты не выданы за shared-capital portfolio.
- [ ] Ограничения исполнения и качества данных указаны.
- [ ] Holdout не использовался для настройки параметров.
